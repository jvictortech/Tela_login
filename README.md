# Modelo de Front-end - Experiência Aplicada em Desenvolvimento Web

Base inicial para os projetos das áreas de **saúde**, **saneamento** e **pets**.

## Objetivo desta etapa

Concluir o front-end do fluxo principal do projeto. As telas devem estar navegáveis e responsivas, ainda que utilizem dados simulados. O back-end e a integração com Python/Flask serão trabalhados na próxima aula.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou utilize a extensão Live Server.
4. Faça uma alteração por vez, salve e teste novamente.

## Tarefas obrigatórias do grupo

- [ ] Substituir `APP` pelo nome ou sigla do sistema.
- [ ] Aplicar a identidade visual definida no protótipo.
- [ ] Criar todas as telas essenciais do fluxo principal.
- [ ] Permitir a navegação entre as telas.
- [ ] Criar pelo menos um formulário relacionado ao projeto.
- [ ] Validar campos vazios e regras mínimas com JavaScript.
- [ ] Exibir mensagens de erro e de sucesso.
- [ ] Testar a visualização em computador e celular.
- [ ] Manter o código organizado em HTML, CSS, JavaScript e `assets`.
- [ ] Registrar as contribuições por meio de branches e commits identificados.

## Fluxo mínimo sugerido

### Saúde

Entrada/cadastro → início → escolha do serviço → agendamento → confirmação.

### Saneamento

Entrada → início → registro da ocorrência → localização/imagem → acompanhamento → confirmação.

### Pets

Entrada → início → cadastro ou busca do animal → detalhes → solicitação → confirmação.

## Critérios do checkpoint

1. Telas essenciais implementadas.
2. Navegação funcionando.
3. Formulários com validação básica.
4. Responsividade.
5. Fidelidade ao protótipo.
6. Organização do repositório e participação dos integrantes.
7. Capacidade de explicar o que foi desenvolvido.

## Ainda não será exigido

- Banco de dados;
- Login ou cadastro verdadeiro;
- Persistência permanente dos dados;
- API completa;
- Sistema pronto para produção.

## Preparação para a próxima aula

Cada grupo deverá informar:

- qual formulário será conectado primeiro ao back-end;
- quais dados serão enviados;
- qual resposta o servidor deverá retornar;

> Importante: o código-base é um ponto de partida. Cada grupo deverá adaptá-lo ao próprio projeto e compreender as alterações realizadas.
