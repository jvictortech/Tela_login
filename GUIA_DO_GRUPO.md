# Guia rápido de organização do grupo

## Antes de começar

1. Liste as telas existentes no protótipo.
2. Marque quais fazem parte do fluxo principal.
3. Defina a ordem de navegação.
4. Distribua tarefas entre os integrantes.

## Sugestão de divisão

- Pessoa 1: estrutura e conteúdo HTML.
- Pessoa 2: identidade visual e responsividade CSS.
- Pessoa 3: validações JavaScript e testes.
- Pessoa 4: navegação, GitHub e registro das contribuições.

Todos os integrantes devem revisar o fluxo e conseguir explicar ao menos uma parte do código.

## Testes obrigatórios

- Envio com campos vazios;
- Entrada abaixo do tamanho mínimo;
- Dados válidos;
- Navegação entre todas as telas;
- Visualização no modo celular;
- Ausência de rolagem horizontal.

## Entrega do checkpoint

Na apresentação rápida, o grupo deverá mostrar:

1. O fluxo principal completo;
2. Uma validação de erro;
3. Uma mensagem de sucesso;
4. O histórico de commits;
5. A contribuição de cada integrante.
